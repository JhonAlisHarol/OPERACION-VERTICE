# Operación Vértice — Consola Operativa (CON-C5)

Aplicación en Streamlit para consolidar, depurar y exportar a Excel (4 bloques horarios y 5 pestañas) los reportes operativos de campo de la **Operación Vértice** (Policía Nacional, SENAFRONT, SNM, ATTT, MINSA, Aduanas y MIDA).

## Estructura del Repositorio
- `app.py`: Aplicación principal de Streamlit.
- `requirements.txt`: Dependencias para Streamlit Community Cloud.
- `.streamlit/config.toml`: Tema institucional ejecutivo.

## Despliegue en Streamlit Cloud desde GitHub
1. Sube estos archivos a tu repositorio de GitHub.
2. En [share.streamlit.io](https://share.streamlit.io), selecciona el repositorio y establece `app.py` como archivo principal.
